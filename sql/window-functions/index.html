Оконные функции (Window Functions)

Оконные функции выполняют вычисления по набору строк, которые связаны с текущей обрабатываемой строкой. В отличие от обычных агрегатных функций (GROUP BY), которые сводят группу строк в одну итоговую запись, оконные функции не схлопывают строки: каждая строка исходной выборки сохраняет свою индивидуальность, получая дополнительное вычисленное значение в новом столбце.

1. Синтаксис и конструкция OVER()​

Базовый синтаксис вызова оконной функции состоит из имени функции и обязательной конструкции OVER(), которая определяет размеры и поведение «окна» (набора строк для расчета).

SELECT 
    employee_id,
    department_id,
    salary,
    AVG(salary) OVER (PARTITION BY department_id) AS dept_avg_salary
FROM employees;

Спецификация окна в OVER(...)​

  • PARTITION BY column1, column2: Разбивает всю выборку на независимые разделы (секции) по значениям колонок. Расчет оконной функции производится изолированно внутри каждой секции и сбрасывается при переходе к следующей. Если PARTITION BY не указан, окном считается весь набор строк запроса.
  • ORDER BY column ASC/DESC: Определяет логический порядок следования строк внутри секции. Обязателен для ранжирующих функций и функций смещения.
  • ROWS / RANGE (Window Frame): Дополнительно сужает окно расчета относительно текущей строки (например, от начала секции до текущей строки ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW).

2. Ранжирующие функции​

Ранжирующие функции присваивают порядковые номера строкам внутри каждой секции на основе сортировки ORDER BY.

ROW_NUMBER()​

Присваивает строкам строго последовательные уникальные целые числа от 1 до N внутри секции. Если значения в столбце сортировки равны (тай-брейк), номера распределяются произвольно.

RANK()​

Присваивает ранг (номер) строке. Если у нескольких строк значения сортировки одинаковы, они получают одинаковый ранг, но ранг следующей отличающейся строки увеличивается с учетом пропущенных номеров (например: 1, 2, 2, 4).

DENSE_RANK()​

Работает аналогично RANK(), но не делает пропусков в нумерации при наличии одинаковых значений (например: 1, 2, 2, 3).

SELECT 
    name,
    salary,
    ROW_NUMBER() OVER (ORDER BY salary DESC) AS row_num,
    RANK() OVER (ORDER BY salary DESC) AS rank_num,
    DENSE_RANK() OVER (ORDER BY salary DESC) AS dense_rank_num
FROM employees;

3. Функции смещения: LAG() и LEAD()​

Функции смещения позволяют получить значение столбца из соседней строки (предыдущей или последующей) относительно текущей строки без выполнения дополнительных соединений таблицы (SELF JOIN).

LAG(column, offset, default)​

Возвращает значение столбца column из строки, находящейся на offset позиций назад (выше) от текущей строки в рамках сортировки окна. Если строка отсутствует (например, на первой строке секции), возвращается значение default (по умолчанию NULL).

LEAD(column, offset, default)​

Возвращает значение столбца column из строки, находящейся на offset позиций вперед (ниже) от текущей строки.

-- Расчет изменения зарплаты по сравнению с предыдущим сотрудником в порядке найма
SELECT 
    name,
    hire_date,
    salary,
    LAG(salary, 1, 0) OVER (ORDER BY hire_date ASC) AS prev_salary,
    salary - LAG(salary, 1, salary) OVER (ORDER BY hire_date ASC) AS salary_diff
FROM employees;

4. Практические примеры и сценарии применения​

Поиск топ-1 или топ-N записей в каждой группе (Top-N per Group)​

Классическая задача: найти самого высокооплачиваемого сотрудника в каждом отделе. Решается через оборачивание запроса с ROW_NUMBER() в подзапрос (или CTE):

WITH RankedEmployees AS (
    SELECT 
        id,
        name,
        department_id,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department_id 
            ORDER BY salary DESC
        ) AS rn
    FROM employees
)
SELECT id, name, department_id, salary
FROM RankedEmployees
WHERE rn = 1;

Расчет нарастающего итога (Running Total)​

Для расчета накопительной суммы продаж по дням используется агрегатная функция SUM() OVER(...) с сортировкой по дате:

SELECT 
    order_date,
    amount,
    SUM(amount) OVER (
        ORDER BY order_date ASC 
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_total
FROM sales;
