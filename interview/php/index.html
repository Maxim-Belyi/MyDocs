Вопросы по PHP

Раздел охватывает базовые и продвинутые темы PHP: типизацию, ООП, магические методы, работу с памятью и генераторы.

1. Типы данных и строгая типизация​

Что делает declare(strict_types=1)?​

Директива отключает неявное приведение типов для скалярных типов (int, float, string, bool) в текущем файле. Без неё PHP молча приведёт строку "42" к int при передаче в функцию с type-hint int. Со strict_types=1 такой вызов вызовет TypeError.

Директива действует только на вызовы из файла, в котором объявлена. Если вызывающий файл без strict_types, приведение типов произойдёт даже у функций из файлов со строгим режимом.

В чём разница между == и ===?​

== — нестрогое сравнение: перед сравнением оба операнда приводятся к общему типу. === — строгое: совпадение и значения, и типа.

Классические ловушки ==:

  • 0 == "foo" → true (PHP 7), false (PHP 8)
  • "1" == "01" → true (числовые строки)
  • null == false → true
  • null == "" → true
  • null == 0 → true

Правило: всегда использовать === для сравнений, где тип имеет значение.

Что такое Union-типы и Intersection-типы?​

  • Union (int|string) — значение может быть любым из перечисленных типов. PHP 8.0+.
  • Intersection (Iterator&Countable) — значение должно реализовывать все перечисленные интерфейсы. PHP 8.1+. Применимо только к объектным типам.

Что такое nullable-тип (?string)?​

Эквивалент string|null. Переменная принимает либо значение указанного типа, либо null.

Что такое Enum в PHP 8.1?​

Перечисление — специальный тип объекта с фиксированным набором значений. Backed Enum хранит скалярное значение (string или int) для каждого кейса. Извлекается через Color::from('red') (или tryFrom — не выбрасывает исключение).

2. ООП​

Чем абстрактный класс отличается от интерфейса?​

Абстрактный классИнтерфейс
НаследованиеТолько от одногоРеализовывать можно несколько
Реализованные методыДа (shared code)Нет (только объявления)
СвойстваЛюбыеТолько константы
Видимость членовpublic, protected, privateТолько public

Правило выбора: Абстрактный класс — если классы разделяют реализацию (is-a). Интерфейс — если нужен контракт поведения для несвязанных классов (can-do).

Что такое трейт? Как разрешить конфликт методов?​

Трейт — механизм горизонтального повторного использования кода. Позволяет "подмешать" методы в класс без наследования. Класс может использовать несколько трейтов.

При конфликте (два трейта с одинаковым именем метода) — PHP выдаёт фатальную ошибку. Решение: явно указать через insteadof (какой использовать) и as (переименовать другой).

Чем self:: отличается от static::?​

  • self:: — ссылается на класс, в котором метод определён (жёсткая привязка).
  • static:: — Late Static Binding — ссылается на класс, из которого метод вызван.
class Parent { public static function create(): static { return new static(); } }
class Child extends Parent {}
Child::create(); // Создаст Child (static::), а не Parent (self::)

Модификаторы видимости: разница между public, protected, private​

  • public — доступен откуда угодно.
  • protected — только в классе и его наследниках.
  • private — только в классе, где объявлен. Не наследуется.

Что такое readonly (PHP 8.1)?​

Свойство, которое можно присвоить только один раз — в конструкторе. После этого попытка изменить значение вызывает ошибку. Используется для создания Value Objects и DTO.

Как Eloquent использует магические методы?​

Eloquent-модели хранят значения в массиве $attributes. Доступ через $user->name перехватывается __get, который проверяет $attributes, casts, accessors. Запись $user->name = 'Alice' перехватывается __set, который применяет mutators и пишет в $attributes.

Что такое __invoke? Где применяется в Laravel?​

__invoke делает объект вызываемым как функцию. В Laravel применяется для:

  • Invokable Controllers (Route::get('/hello', HelloController::class))
  • Middleware
  • Artisan Commands
  • Замыканий, завёрнутых в класс

Что такое clone и зачем нужен __clone?​

clone создаёт поверхностную копию (shallow copy): примитивы и массивы копируются по значению, но вложенные объекты — по ссылке (оба экземпляра будут указывать на один объект). __clone вызывается сразу после клонирования и позволяет сделать глубокое копирование: $this->address = clone $this->address;.

4. Память и производительность​

Как работают ссылки в PHP?​

Оператор & создаёт псевдоним — два имени для одного значения (zval). Изменение через любое имя меняет значение.

Ловушка в foreach: после итерации foreach ($arr as &$item) переменная $item остаётся ссылкой на последний элемент массива. Следующий foreach по тому же массиву перезапишет последний элемент. Решение: unset($item) после цикла.

Как работает сборщик мусора в PHP?​

PHP использует reference counting: у каждого значения есть счётчик ссылок. Когда он падает до 0 — память освобождается немедленно.

Проблема: циклические ссылки (A → B → A) не опускают счётчик до 0. Для них есть Zend Cycle Garbage Collector: он периодически обходит граф объектов, находит недостижимые циклические структуры и освобождает их. Запускается автоматически при 10 000 потенциально циклических переменных. Вручную: gc_collect_cycles().

Зачем нужны генераторы (yield)? Как экономят память?​

Обычная функция возвращает сразу весь результат. Генератор — функция с yield, которая приостанавливает выполнение и возвращает одно значение. При следующем запросе продолжает с того же места.

Экономия памяти: вместо загрузки 1 000 000 строк файла в массив (сотни МБ) — обрабатываем по одной строке (несколько КБ). В Laravel: Model::cursor() вместо Model::get() при обработке больших таблиц.

Что такое Copy-on-Write (CoW)?​

PHP не копирует данные при простом присваивании $b = $a — они указывают на один zval с refcount=2. Копия создаётся только при изменении одной из переменных. Это позволяет передавать большие массивы в функции без накладных расходов на копирование (если функция не изменяет массив).

5. Дополнительные темы​

Что такое Fiber (PHP 8.1)?​

Fiber — аналог корутин/зелёных потоков. Позволяет приостанавливать и возобновлять выполнение кода изнутри (через Fiber::suspend()). В отличие от генераторов, Fiber не ограничен одной функцией — можно приостановить на любой глубине стека вызовов. Используется в библиотеках для асинхронного программирования (ReactPHP, Amp).

Разница между require, require_once, include, include_once?​

  • include — включает файл, при ошибке выдаёт Warning и продолжает выполнение.
  • require — включает файл, при ошибке выдаёт Fatal Error и останавливает выполнение.
  • *_once — дополнительно проверяет, не был ли файл уже включён. Если да — пропускает.

Что такое match (PHP 8.0)?​

Строгое выражение-сопоставление. В отличие от switch:

  • Использует строгое сравнение (===).
  • Возвращает значение (это выражение, а не оператор).
  • Не требует break.
  • Выбрасывает UnhandledMatchError при несовпадении (vs switch молча пропускает).
$result = match($status) {
    'active'   => 'Активен',
    'inactive' => 'Неактивен',
    default    => throw new \InvalidArgumentException("Unknown status: $status"),
};
