Вопросы по Laravel

Раздел охватывает ключевые темы Laravel: жизненный цикл запроса, Eloquent ORM, Service Container, очереди и REST API.

1. Жизненный цикл запроса​

Что происходит от момента HTTP-запроса до отправки ответа?​

  1. public/index.php — точка входа. Подключает автозагрузчик Composer, создаёт Application (Service Container), передаёт управление Http\Kernel.
  2. Http\Kernel::handle() — загружает Service Providers (register() у всех, затем boot() у всех), применяет глобальные middleware.
  3. Router::dispatch() — находит маршрут по URI и HTTP-методу, применяет group и route middleware.
  4. Контроллер — выполняет бизнес-логику, возвращает Response.
  5. Middleware (обратный ход) — post-processing ответа.
  6. send() — отправка HTTP-ответа клиенту.
  7. Kernel::terminate() — финализация (логи, закрытие сессий).

В чём разница между register() и boot() в Service Provider?​

  • register() — только биндинги в контейнер. Вызывается у всех провайдеров поочерёдно. Здесь нельзя использовать зависимости из других провайдеров (они могут быть ещё не зарегистрированы).
  • boot() — вызывается после того, как все register() завершены. Здесь уже можно использовать любые зависимости, регистрировать event listeners, валидационные правила, view composers.

Что такое Route Model Binding?​

Механизм, при котором Laravel автоматически находит Eloquent-модель по параметру маршрута. Если параметр совпадает по имени с типом аргумента контроллера — Laravel делает Model::findOrFail($id) автоматически. При отсутствии записи возвращает HTTP 404.

Route::get('/users/{user}', [UserController::class, 'show']);
public function show(User $user): JsonResponse { /* $user уже найден */ }

2. Eloquent ORM​

Что такое проблема N+1? Как диагностировать и решить?​

При ленивой загрузке связей в цикле для каждой записи выполняется отдельный SQL-запрос. Для N записей — 1 запрос на коллекцию + N запросов на связи = N+1.

Диагностика: Model::preventLazyLoading() в local-среде (выбрасывает исключение), DB::listen() для логирования, пакет Debugbar или Clockwork.

Решение: Eager Loading — Post::with(['author', 'category'])->get(). Независимо от N выполнится 3 запроса.

Чем отличается Lazy Loading от Eager Loading?​

  • Lazy Loading — связь загружается при первом обращении к ней ($post->author). Запрос происходит в момент обращения.
  • Eager Loading — связи загружаются вместе с основной моделью (with('author')). Дополнительный SELECT ... WHERE id IN (...) происходит сразу.

Что такое Local Scope и Global Scope?​

  • Local Scope — метод модели с префиксом scope. Вызывается явно в построителе запросов: User::active()->get(). Может принимать параметры.
  • Global Scope — применяется ко всем запросам к модели автоматически (например, SoftDeletes добавляет WHERE deleted_at IS NULL). Отключается через withoutGlobalScope().

Что такое Accessors и Mutators?​

  • Accessor — геттер, преобразующий значение при чтении атрибута. $user->name → ucfirst.
  • Mutator — сеттер, преобразующий значение при записи. $user->name = 'ALICE' → сохранится как 'alice'.

В Laravel 9+ реализуются через Attribute::make(get: fn, set: fn).

Что такое $casts?​

Массив правил автоматического приведения типов атрибутов модели. Например, 'metadata' => 'array' автоматически конвертирует JSON из БД в PHP-массив и обратно. 'status' => OrderStatus::class — автоматическое приведение к PHP 8.1 Enum.

Чем chunk() отличается от cursor()?​

  • chunk(1000, fn) — загружает по 1000 записей батчами. В памяти одновременно находится 1000 объектов Eloquent.
  • cursor() — возвращает генератор. В памяти одновременно находится 1 запись. Потребление O(1) памяти vs O(N) у chunk.

Что такое SoftDeletes?​

Мягкое удаление: вместо физического удаления устанавливается поле deleted_at. Глобальный scope автоматически фильтрует такие записи. withTrashed() включает их в запрос, onlyTrashed() возвращает только их, restore() восстанавливает, forceDelete() удаляет физически.

3. Service Container и Facades​

Что такое Service Container?​

IoC-контейнер (Inversion of Control) — центральный реестр приложения. Умеет хранить биндинги (интерфейс → реализация) и автоматически разрешать зависимости через рефлексию. Позволяет заменить реализацию в одном месте без изменения всего кода.

Разница между bind() и singleton()?​

  • bind() — каждый раз при разрешении создаётся новый экземпляр.
  • singleton() — экземпляр создаётся один раз, при повторных разрешениях возвращается тот же объект.
  • scoped() — как singleton, но сбрасывается между запросами (актуально для Laravel Octane).

Как работают Facades под капотом?​

Facade — это класс с методом getFacadeAccessor(), возвращающим ключ в контейнере. При вызове статического метода Cache::get('key') перехватывается __callStatic, который получает реальный объект из контейнера и вызывает метод на нём. Статических методов как таковых нет — это проксирование к контейнеру.

В чём разница между Facade и DI через конструктор?​

  • Facade: глобальный доступ, удобен для быстрого написания, сложнее мокировать без специального API (Cache::shouldReceive(...)).
  • DI: явные зависимости в конструкторе, легко мокируется стандартными средствами PHPUnit, соответствует принципу явности.

Для классов с тестами рекомендован DI. Facades удобны в роутах, командах, сервис-провайдерах.

4. Очереди и планировщик​

Как устроены Queue Jobs в Laravel?​

Job — класс, реализующий ShouldQueue. При вызове dispatch(new Job(...)) сериализованный объект помещается в очередь (Redis/SQS/DB). Воркер (queue:work) читает задачи из очереди и вызывает handle().

Что такое tries, timeout, backoff?​

  • $tries — максимальное количество попыток выполнения.
  • $timeout — максимальное время выполнения задачи в секундах.
  • backoff() — задержка перед повторной попыткой (массив задержек в секундах для каждой попытки, поддерживает exponential backoff).

Что такое Failed Jobs?​

Задача попадает в failed_jobs после исчерпания всех попыток. Вызывается метод failed(Throwable $e) на классе задачи. Управление: queue:retry, queue:forget, queue:flush.

Чем отличается queue:work от queue:listen?​

  • queue:work — загружает приложение один раз в память и обрабатывает несколько задач. Производительнее. Требует рестарта при деплое (queue:restart).
  • queue:listen — перезапускает процесс для каждой задачи. Медленнее, но автоматически подхватывает изменения кода.

Как работает Task Scheduling?​

В crontab добавляется одна запись: * * * * * php artisan schedule:run. Планировщик сам проверяет, какие задачи нужно запустить в данную минуту. Расписание задаётся в App\Console\Kernel::schedule(). withoutOverlapping() защищает от параллельного запуска одной задачи.

5. REST API​

Что такое API Resource и зачем он нужен?​

JsonResource — трансформационный слой между моделью и JSON-ответом. Позволяет контролировать, какие поля отдаются, в каком формате, и не зависеть от структуры модели. whenLoaded('posts') включает связь в ответ только если она была загружена через with() — защита от N+1.

В чём разница между Sanctum и Passport?​

  • Sanctum: лёгкое решение. Два режима: API-токены (мобильные приложения) и cookie-сессии (SPA на том же домене). Не полноценный OAuth2.
  • Passport: полноценный OAuth2-сервер. Нужен для выдачи токенов сторонним разработчикам, refresh tokens, Authorization Code flow.

Что такое Form Request и как работает authorize()?​

FormRequest — класс, инкапсулирующий валидацию и авторизацию. authorize() возвращает bool: если false — HTTP 403 без вызова контроллера. rules() возвращает массив правил; при провале — HTTP 422 с JSON-ошибками. validated() в контроллере возвращает только провалидированные поля.

Как версионировать API в Laravel?​

Через префикс маршрутов: Route::prefix('v1')->group(...) и Route::prefix('v2')->group(...). Альтернатива — через заголовок Accept: application/vnd.myapp.v2+json с кастомным middleware.

6. Дополнительные темы​

Что такое Middleware и как создать своё?​

Middleware — класс с методом handle(Request $request, Closure $next). Получает запрос, выполняет логику (например, проверку токена), и либо передаёт запрос дальше ($next($request)), либо возвращает ответ досрочно. Регистрируется в Kernel.php.

Что такое Event и Listener?​

Event — класс-событие (факт, что что-то произошло). Listener — обработчик события. Разрывает прямую связь между компонентами: вместо явного вызова $mailer->send(...) в сервисе — event(new UserRegistered($user)), а Listener отправит письмо. Регистрируется в EventServiceProvider.

Что такое Policy?​

Policy — класс авторизации, определяющий права пользователя на действия с моделью. Методы: viewAny, view, create, update, delete. Вызывается через $this->authorize('update', $post) в контроллере или @can('update', $post) в Blade.

Что такое миграции и почему не стоит редактировать уже применённые?​

Миграция — описание изменений схемы БД, которое применяется один раз. up() применяет, down() откатывает. Редактировать применённую миграцию нельзя — другие разработчики и production-серверы уже выполнили её. Вместо этого создаётся новая миграция.

Как работает кэширование в Laravel?​

Через Facade Cache или DI CacheInterface. Поддерживает несколько драйверов: file, redis, memcached, array (для тестов). Основные операции: Cache::put(key, value, ttl), Cache::get(key), Cache::remember(key, ttl, fn) (get-or-set), Cache::forget(key), Cache::tags(['posts'])->flush() (для тегированного кэша на Redis).
