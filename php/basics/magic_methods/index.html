Магические методы

Магические методы — это специальные методы с предопределёнными именами (начинаются на __), которые PHP вызывает автоматически при определённых событиях: создании объекта, обращении к несуществующему свойству, приведении объекта к строке и т.д. Понимание их назначения и порядка вызова — частый вопрос на собеседованиях.

1. __construct и __destruct​

class DatabaseConnection
{
    private \PDO $pdo;

    public function __construct(string $dsn, string $user, string $password)
    {
        // Вызывается при создании объекта через new
        $this->pdo = new \PDO($dsn, $user, $password);
        echo "Соединение установлено\n";
    }

    public function __destruct()
    {
        // Вызывается автоматически, когда объект уничтожается:
        // - выходит из области видимости
        // - явно unset($obj)
        // - завершается скрипт
        echo "Соединение закрыто\n";
        // $this->pdo = null; — PDO закроет соединение само при GC
    }
}

Порядок вызова __destruct: Деструкторы вызываются в порядке, обратном созданию объектов. При завершении скрипта вызываются для всех оставшихся объектов.

2. __get, __set, __isset, __unset — перегрузка свойств​

Вызываются при обращении к недоступным (несуществующим или непубличным) свойствам.

class MagicProperties
{
    private array $data = [];
    private array $readOnly = ['id'];

    // Вызывается при чтении недоступного свойства: $obj->name
    public function __get(string $name): mixed
    {
        return $this->data[$name] ?? null;
    }

    // Вызывается при записи в недоступное свойство: $obj->name = "Alice"
    public function __set(string $name, mixed $value): void
    {
        if (in_array($name, $this->readOnly)) {
            throw new \RuntimeException("Property '$name' is read-only");
        }
        $this->data[$name] = $value;
    }

    // Вызывается при isset($obj->name) или empty($obj->name)
    public function __isset(string $name): bool
    {
        return isset($this->data[$name]);
    }

    // Вызывается при unset($obj->name)
    public function __unset(string $name): void
    {
        unset($this->data[$name]);
    }
}

$obj = new MagicProperties();
$obj->name = 'Alice';        // __set
echo $obj->name;             // __get → Alice
echo isset($obj->name);      // __isset → true
unset($obj->name);           // __unset

Практическое применение: Eloquent-модели используют __get и __set для доступа к атрибутам ($user->name обращается не к реальному свойству, а к внутреннему массиву $attributes).

3. __call и __callStatic — перегрузка методов​

class ApiClient
{
    private array $endpoints = [
        'getUser'    => '/users/{id}',
        'getOrders'  => '/orders',
    ];

    // Вызывается при вызове недоступного нестатического метода
    public function __call(string $name, array $arguments): mixed
    {
        if (!isset($this->endpoints[$name])) {
            throw new \BadMethodCallException("Method '$name' not found");
        }

        $url = $this->endpoints[$name];
        return $this->request($url, $arguments);
    }

    // Вызывается при вызове недоступного статического метода
    public static function __callStatic(string $name, array $arguments): mixed
    {
        $instance = new static();
        return $instance->$name(...$arguments);
    }

    private function request(string $url, array $params): array
    {
        // HTTP запрос...
        return [];
    }
}

$client = new ApiClient();
$user = $client->getUser(1); // Перехватывает __call

Практическое применение: Facades в Laravel используют __callStatic для проксирования вызовов к реальным объектам из Service Container.

4. __toString — строковое представление​

Вызывается при явном или неявном приведении объекта к строке: echo $obj, (string) $obj, конкатенация со строкой.

class Money
{
    public function __construct(
        private int $amount,
        private string $currency
    ) {}

    public function __toString(): string
    {
        return number_format($this->amount / 100, 2) . ' ' . $this->currency;
    }
}

$price = new Money(9990, 'RUB');
echo $price;              // 99.90 RUB
echo "Цена: $price";      // Цена: 99.90 RUB
$str = (string) $price;   // "99.90 RUB"

Начиная с PHP 8.0 классы с __toString автоматически реализуют интерфейс Stringable.

5. __invoke — объект как функция​

Вызывается при попытке вызвать объект как функцию: $obj(...).

class Multiplier
{
    public function __construct(private int $factor) {}

    public function __invoke(int $value): int
    {
        return $value * $this->factor;
    }
}

$double = new Multiplier(2);
$triple = new Multiplier(3);

echo $double(5);  // 10
echo $triple(5);  // 15

// Объект можно передавать как callable
$numbers = [1, 2, 3, 4, 5];
$doubled = array_map($double, $numbers); // [2, 4, 6, 8, 10]

// Проверка: is_callable вернёт true для объекта с __invoke
var_dump(is_callable($double)); // bool(true)

Практическое применение: Middleware в Laravel и команды в Command Bus часто реализуются как инвоцируемые классы (__invoke).

6. __clone — клонирование объектов​

Оператор clone создаёт поверхностную копию объекта (shallow copy). Вложенные объекты при этом не копируются — копируются только ссылки на них. Метод __clone вызывается сразу после клонирования и позволяет сделать глубокое копирование (deep copy).

class UserProfile
{
    public array $tags = [];
    public Address $address;

    public function __clone()
    {
        // Без этого $clone->address === $original->address (одна ссылка!)
        $this->address = clone $this->address;
        // Массивы копируются автоматически (value type в PHP)
    }
}

class Address
{
    public function __construct(public string $city) {}
}

$original = new UserProfile();
$original->address = new Address('Moscow');
$original->tags = ['admin', 'user'];

$clone = clone $original;
$clone->address->city = 'Kazan';
$clone->tags[] = 'moderator';

echo $original->address->city; // Moscow (не изменился — глубокое копирование)
print_r($original->tags);      // ['admin', 'user'] (массив скопирован по значению)

7. __serialize и __unserialize (PHP 7.4+)​

Управляют сериализацией объекта через serialize() и unserialize(). Заменяют устаревшие __sleep и __wakeup.

class Session
{
    private string $token;
    private \PDO $db; // Не должна сериализоваться (ресурс)

    public function __serialize(): array
    {
        // Возвращаем только то, что нужно сохранить
        return ['token' => $this->token];
    }

    public function __unserialize(array $data): void
    {
        // Восстанавливаем состояние из сохранённых данных
        $this->token = $data['token'];
        $this->db = new \PDO(/* ... */); // Восстанавливаем соединение
    }
}
