Типы данных и строгая типизация

PHP — динамически типизированный язык, однако начиная с версии 7.0 последовательно вводится поддержка строгой типизации. Понимание системы типов и её ловушек является базовым требованием на любом собеседовании.

1. Скалярные типы​

PHP поддерживает четыре скалярных типа:

ТипОписаниеПример
intЦелое число42, -7, 0x1A
floatЧисло с плавающей точкой3.14, 1.2e3
stringСтрока байтов"hello", 'world'
boolЛогическое значениеtrue, false

2. declare(strict_types=1) — строгая типизация​

По умолчанию PHP выполняет неявное приведение типов при передаче аргументов в функцию. Если функция ожидает int, а передана строка "42", PHP молча конвертирует её.

Директива declare(strict_types=1) в начале файла отключает неявное приведение. В строгом режиме передача "42" вместо int вызовет TypeError.

declare(strict_types=1);

function add(int $a, int $b): int
{
    return $a + $b;
}

add(1, 2);    // 3 — корректно
add("1", 2);  // TypeError — строка не принимается, даже если это числовая строка

Важно: директива действует только на текущий файл. Файл, вызывающий функцию, определяет, применяется ли строгий режим. Если вызывающий файл без strict_types, неявное приведение произойдёт даже для функции из файла со strict_types.

3. Nullable-типы (?Type)​

Знак ? перед типом означает, что переменная может принимать значение данного типа или null.

function findUser(int $id): ?User
{
    return User::find($id); // Вернёт User или null, если не найден
}

function greet(?string $name): string
{
    return 'Hello, ' . ($name ?? 'Guest');
}

4. Union-типы (PHP 8.0+)​

Union-тип позволяет принять значения нескольких типов. Типы перечисляются через |.

function processInput(int|string $input): string
{
    if (is_int($input)) {
        return "Number: $input";
    }
    return "String: $input";
}

// Nullable через union — два эквивалентных способа:
function example(?string $s): void {}
function example(string|null $s): void {} // То же самое

5. Intersection-типы (PHP 8.1+)​

Intersection-тип требует, чтобы значение реализовывало все перечисленные интерфейсы. Типы перечисляются через &. Применимо только к объектным типам.

interface Countable {}
interface Iterator {}

function process(Iterator&Countable $collection): void
{
    // Принимается только объект, реализующий оба интерфейса
}

6. Специальные типы​

ТипОписание
mixedЛюбой тип (PHP 8.0+). Явное указание на то, что тип намеренно не ограничен
voidФункция ничего не возвращает (return; или без return)
neverФункция никогда не завершается нормально: бросает исключение или вызывает exit() (PHP 8.1+)
arrayМассив (индексированный или ассоциативный)
callableЛюбое вызываемое значение: функция, замыкание, массив [объект, метод]
objectЛюбой объект
selfТекущий класс
staticТекущий класс с поздним связыванием (Late Static Binding)

7. == vs === — ловушки нестрогого сравнения​

Нестрогое сравнение == выполняет приведение типов перед сравнением. Это источник труднодиагностируемых ошибок.

0 == "foo"      // true в PHP 7 (строка приводится к 0), false в PHP 8
0 == ""         // true в PHP 7, false в PHP 8
"1" == "01"     // true (числовые строки сравниваются как числа)
"10" == "1e1"   // true (1e1 == 10.0)
100 == "1e2"    // true
null == false   // true
null == 0       // true
null == ""      // true

PHP 8 значительно исправил поведение == для сравнения 0 со строками, однако использование === (строгое сравнение типа и значения) остаётся рекомендованной практикой.

0 === "0"   // false — разные типы
0 === 0     // true
"1" === 1   // false
null === false // false

8. Приведение типов​

Явное приведение выполняется через оператор (type):

$str = "42abc";
$int = (int) $str;    // 42  (PHP читает число до первого нечислового символа)
$flt = (float) $str;  // 42.0
$bool = (bool) $str;  // true (непустая строка)

(bool) "";    // false
(bool) "0";   // false (единственная строка, кроме пустой, дающая false)
(bool) [];    // false (пустой массив)
(bool) null;  // false
(bool) 0;     // false
(bool) 0.0;   // false

9. Перечисления — Enums (PHP 8.1+)​

Enums — это специальный тип объекта с фиксированным набором допустимых значений. Заменяют паттерн с константами класса.

// Pure enum (без значений)
enum Status
{
    case Active;
    case Inactive;
    case Pending;
}

// Backed enum (со строковыми или целочисленными значениями)
enum Color: string
{
    case Red   = 'red';
    case Green = 'green';
    case Blue  = 'blue';
}

function setStatus(Status $status): void
{
    // Теперь компилятор/IDE проверяет, что передан именно Status
}

setStatus(Status::Active);

// Получить значение backed enum
$color = Color::Red;
echo $color->value; // "red"

// Получить enum из значения
$color = Color::from('green'); // Color::Green
$color = Color::tryFrom('invalid'); // null (не выбрасывает исключение)
