ООП в PHP

PHP поддерживает полноценную объектно-ориентированную модель: классы, интерфейсы, абстрактные классы, трейты и наследование. Понимание различий между этими инструментами — обязательное требование на собеседовании уровня Middle+.

1. Классы и объекты​

class User
{
    // Свойства с типами (PHP 7.4+)
    public int $id;
    public string $name;
    protected string $email;
    private string $passwordHash;

    // Конструктор
    public function __construct(int $id, string $name, string $email)
    {
        $this->id    = $id;
        $this->name  = $name;
        $this->email = $email;
    }

    // Публичный метод
    public function getEmail(): string
    {
        return $this->email;
    }

    // Приватный метод
    private function hashPassword(string $password): string
    {
        return password_hash($password, PASSWORD_BCRYPT);
    }
}

$user = new User(1, 'Alice', 'alice@example.com');
echo $user->name; // Alice

Constructor Promotion (PHP 8.0+)​

Сокращённый синтаксис: объявление свойств прямо в параметрах конструктора.

class User
{
    public function __construct(
        public readonly int $id,
        public string $name,
        protected string $email,
    ) {}
}

readonly-свойства (PHP 8.1+)​

Свойство может быть присвоено только один раз — в конструкторе. После этого оно неизменяемо.

class Money
{
    public function __construct(
        public readonly int $amount,
        public readonly string $currency,
    ) {}
}

$m = new Money(100, 'RUB');
$m->amount = 200; // Error: Cannot modify readonly property

2. Модификаторы видимости​

МодификаторДоступен вДоступен в наследникахДоступен снаружи

protectedДаДаНет

private-свойства/методы не наследуются. Дочерний класс может объявить собственный private-член с тем же именем — это будут два разных члена.

3. Статические члены​

Статические свойства и методы принадлежат классу, а не экземпляру. Доступ через ::.

class Counter
{
    private static int $count = 0;

    public static function increment(): void
    {
        self::$count++;
    }

    public static function getCount(): int
    {
        return self::$count;
    }
}

Counter::increment();
Counter::increment();
echo Counter::getCount(); // 2

4. Абстрактные классы vs Интерфейсы​

Это наиболее частый вопрос на собеседовании.

Абстрактный класс (abstract class)Интерфейс (interface)
НаследованиеОдин класс (нет множественного)Класс может реализовывать несколько
МетодыМожет содержать реализованные и абстрактные методыТолько объявления (до PHP 8.0), с PHP 8.0 — дефолтные методы недоступны; константы и объявления
СвойстваМогут быть любыеКонстанты (не свойства)
КонструкторМожет бытьНет
Модификаторыpublic, protected, privateВсе члены неявно public

Когда использовать абстрактный класс:​

Когда у нескольких классов есть общий код (общая реализация), который нужно вынести в одно место, и при этом они разделяют общую природу (is-a relationship).

abstract class Shape
{
    abstract public function area(): float; // Каждая фигура сама считает площадь

    // Общая реализация для всех фигур
    public function describe(): string
    {
        return sprintf('%s с площадью %.2f', static::class, $this->area());
    }
}

class Circle extends Shape
{
    public function __construct(private float $radius) {}

    public function area(): float
    {
        return M_PI * $this->radius ** 2;
    }
}

Когда использовать интерфейс:​

Когда нужно определить контракт (набор методов), которому должны соответствовать не связанные между собой классы.

interface Exportable
{
    public function toArray(): array;
    public function toJson(): string;
}

interface Loggable
{
    public function getLogMessage(): string;
}

// Один класс может реализовывать несколько интерфейсов
class Order implements Exportable, Loggable
{
    public function toArray(): array { /* ... */ }
    public function toJson(): string { /* ... */ }
    public function getLogMessage(): string { /* ... */ }
}

5. Трейты (Traits)​

Трейт — механизм горизонтального повторного использования кода. Позволяет подмешать методы в класс без наследования. Класс может использовать несколько трейтов.

trait Timestampable
{
    private \DateTimeImmutable $createdAt;
    private \DateTimeImmutable $updatedAt;

    public function touch(): void
    {
        $this->updatedAt = new \DateTimeImmutable();
    }

    public function getCreatedAt(): \DateTimeImmutable
    {
        return $this->createdAt;
    }
}

trait SoftDeletable
{
    private ?\DateTimeImmutable $deletedAt = null;

    public function softDelete(): void
    {
        $this->deletedAt = new \DateTimeImmutable();
    }

    public function isDeleted(): bool
    {
        return $this->deletedAt !== null;
    }
}

class Post
{
    use Timestampable, SoftDeletable; // Используем оба трейта

    public function __construct(public string $title) {}
}

Разрешение конфликтов​

Если два трейта определяют метод с одинаковым именем, PHP вызывает фатальную ошибку. Конфликт разрешается явно через insteadof и as:

trait A { public function hello(): string { return 'A'; } }
trait B { public function hello(): string { return 'B'; } }

class C
{
    use A, B {
        A::hello insteadof B; // Использовать hello из A, игнорировать из B
        B::hello as helloFromB; // Переименовать метод из B
    }
}

$c = new C();
echo $c->hello();       // A
echo $c->helloFromB();  // B

6. Позднее статическое связывание (static:: vs self::)​

self:: всегда ссылается на класс, в котором метод определён (жёсткая привязка к классу-владельцу). static:: ссылается на класс, из которого метод вызван (позднее связывание, Late Static Binding).

class ParentClass
{
    public static function create(): static
    {
        return new static(); // static:: — создаст экземпляр вызывающего класса
    }

    public static function whoAmI(): string
    {
        return static::class; // имя вызывающего класса
    }
}

class ChildClass extends ParentClass {}

$parent = ParentClass::create(); // Создаст ParentClass
$child  = ChildClass::create();  // Создаст ChildClass (!)

echo ParentClass::whoAmI(); // ParentClass
echo ChildClass::whoAmI();  // ChildClass

7. Интерфейсы из SPL (стандартные)​

PHP поставляется с набором стандартных интерфейсов, которые интегрируются с языковыми конструкциями:

ИнтерфейсПозволяет
CountableИспользовать count($obj)
IteratorИтерировать объект через foreach
ArrayAccessОбращаться к объекту как к массиву: $obj['key']
StringableИспользовать объект там, где ожидается строка (автоматически реализуется при __toString)
ThrowableБазовый интерфейс для Error и Exception

8. Наследование и parent::​

class Animal
{
    public function __construct(protected string $name) {}

    public function speak(): string
    {
        return "$this->name издаёт звук";
    }
}

class Dog extends Animal
{
    public function speak(): string
    {
        $base = parent::speak(); // Вызов метода родителя
        return "$base: Гав!";
    }
}

$dog = new Dog('Шарик');
echo $dog->speak(); // Шарик издаёт звук: Гав!

Класс в PHP может наследоваться только от одного класса (extends). Для множественного поведения используются трейты и интерфейсы.
